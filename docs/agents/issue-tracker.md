# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues.
Use the `gh` CLI for reading, creating, commenting on, labeling, and closing issues.
Infer the repository from the current Git remote.

Pull requests as a triage surface: no.

When a skill says "publish to the issue tracker", create a GitHub issue.
When a skill says "fetch the relevant ticket", read the corresponding GitHub issue and its comments.

Wayfinder maps and child tickets use GitHub issues, sub-issues, labels,
assignees, and native issue dependencies where available.
